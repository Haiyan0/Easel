# 503 修复历史诊断材料

本目录保存 2026-11-02～03 主审使用的诊断报告和 13 个故障探针，用于解释修复缘由。对应实现已合入主分支；当前状态见 [最终验收记录](../../superpowers/audits/2026-11-03-acceptance-503-repair-accepted.md)。

这些脚本针对当时的基线、内部接口和测试夹具，有些以“旧缺陷仍然存在”为成功条件。修复后执行可能按预期失败，**不是当前版本的通过性测试，也不是部署命令**。部分探针要求传入特定源码根目录；不得对运行中的用户数据库、workspace 或 provisioner 执行。

日常开发使用 `tests/multiuser` 中已维护的正式回归测试。目录内报告中的实例 ID、提交和本机路径均为历史现场，不作为新部署参数。日常部署请使用 [Windows 手册](../../windows-desktop-operations.zh-CN.md)。
