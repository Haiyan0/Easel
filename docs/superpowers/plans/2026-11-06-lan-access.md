# 局域网 HTTPS 访问实施计划

> 按用户“直接开始改”指令在当前会话执行；本次新增独立文件，保留现有未提交工作。

**目标：** 同一局域网用户通过主机 IP 的 HTTPS 入口使用现有多人实例，IP 变化后重新运行脚本更新来源和证书。

**架构：** Windows Caddy 使用持久化内部 CA，代理到既有回环 control 端口；保持 Secure Cookie 与严格 Origin 校验。复用 Start-WorkspaceEasel.ps1，以登记的固定镜像及工作目录重启；不改业务服务或容器隔离。

**技术：** PowerShell、Caddy 2.11.9、Python pytest。

## 约束与验收重点

- 仅接受 RFC1918 IPv4；自动发现仅选带默认网关的实体网卡，多个候选时要求显式指定。
- HTTPS 端口、后端端口与代理管理端口不得冲突；管理端口只监听回环。
- CA 存储持久化，IP 变化后客户端不必再次导入同一个根证书；只分发根公钥。
- 使用 CurrentUser 根证书库；防火墙规则只放行指定入口与当前子网，需要管理员权限。
- 不改写 Origin，不取消登录保护；新入口生效后旧公网入口不再支持写入。
- 日常重启重新运行脚本；不自动注册开机任务；机器未启动服务时用户仅换地址无效。
- 先生成与验证代理配置，再切换服务；保留原始来源用于回退。
