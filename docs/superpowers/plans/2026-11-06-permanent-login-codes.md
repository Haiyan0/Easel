# 永久登录码与单账号单会话实施计划

用户已要求直接修改：邀请码长期绑定原账号，可跨电脑反复登录，新登录挤掉旧登录。

## 设计

- 默认签发永久、可重复使用的登录码，`expiresAt=0` 表示永久；保留显式有限 TTL 供恢复等管理流程使用，默认 CLI/API 均永久。
- schema 16 将旧库未撤销的邀请（包括已用、已过期）转为永久；已撤销或被禁用账号的码不复活。保留原摘要、账号、工作区与首次使用时间，不保存明文。
- 每次成功登录在同一写事务里撤销该账号其他登录，再创建新登录；无效码、来源失败、限速不得踢掉现有登录。并发登录后只允许最后提交的一份会话有效。
- 已用的码也允许管理员撤销；禁用成员和恢复副本时撤销所有码，不能遗漏历史已用码。
- 保留登录 Cookie 有效期、CSRF 和失败限速。旧浏览器下次请求收到 401 后回到登录页；已接纳任务不因会话切换取消。
- 登录页与成员管理页明确显示“永久登录码、重复登录、新登录使旧登录失效”；账号凭证仅签发时显示一次。
