## 4. 令牌、生命周期与 CSRF

- 邀请与登录使用分别生成的 secrets.token_urlsafe(32) 随机值；摘要保存，不存登录 token 明文。CLI 邀请仅首次输出明文，日志/异常/repr 不回显。
- 邀请默认 7 天有效且单次兑换。失效、撤销、重复、格式不合法等兑换失败统一 401；参数上限和非法 TTL 明确拒绝。
- 浏览器登录默认闲置 24 小时失效、绝对有效期 7 天。滑动更新 last_seen 不得延长绝对期限；边界用注入 clock 验证，不通过 sleep 等待。
- me 返回 userId、workspaceId、role、capabilities、csrfToken；用户角色与禁用状态每次来自数据库。不能把长期登录 token 返回给前端 JS。
- CSRF 方案需支持刷新、服务重启后重新获取并验证 token，数据库仍只保存规定的摘要。说明如何从当前登录安全恢复/派生 CSRF；不要把随机 CSRF 只存内存导致刷新后无法验证，也不要将长期登录 token 直接当 CSRF 回传。
- 登录 Cookie：__Host-easel_session；Secure、HttpOnly、SameSite=Lax、Path=/、无 Domain。注销清除同名同路径 Cookie 并撤销当前登录；revoke_all 使该用户其他登录全部失效。

## 5. HTTP 边界

- POST /api/auth/exchange：请求体含 token，不接收 URL token；校验精确 Origin，不要求尚不存在的登录 CSRF。
- GET /api/auth/me：校验 Cookie 登录，返回上述脱敏身份视图，Cache-Control: no-store。
- POST /api/auth/logout：校验 Origin 与 X-CSRF-Token，持久撤销当前登录。错误请求不能先清掉或改变有效登录。
- 仅最小 health（无内部详情）和兑换等明确公开路由无需认证。未知接口不可回落/透传原有 Web 应用；未装配的依赖显式不可用，不回退 local。
- 公共 Origin 来自管理员明确配置；生产公共站点使用 HTTPS，可由反向代理终止 TLS。不能仅凭客户端 Host/Forwarded/X-Forwarded-* 断定可信 Origin、HTTPS 或来源 IP。
- 兑换失败按来源与令牌摘要限速：10 分钟最多 10 次，超限 429 + Retry-After。不要记录原始 token；多 AuthService/连接不能通过重建对象绕过计数。
- HTTP 测试使用 https://easel.test，并真实读取 Cookie，不 mock authenticate 或绕过角色检查。

7. 退出后 Cookie 清除且旧 token 不能再认证；其他登录是否保留符合当前注销语义。
8. revoke_all、用户禁用、角色变更在另一 AuthService/新连接上立即可见；不能相信伪造 Identity.role。
