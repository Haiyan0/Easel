## 稳定接口

```python
ConfigService(store: Store, master_key: bytes)  # 32 字节
publish(actor, settings: dict, expected_version: int) -> int
resolve(actor, channel: str) -> EffectiveRoute
save_override(actor, channel: str, route: dict) -> None
clear_override(actor, channel: str) -> None
public_settings(actor) -> dict
```

沿用现有 EffectiveRoute 字段。resolve 只返回 credential_ref，不返回明文秘密。完整输入 route 包含 provider/model/base_url/protocol/secret/options；source、credential_ref、version 均由服务端产生，客户端不能指定别人的引用或配置归属。model-only 采用显式 route_kind="managed-model"，不靠缺字段猜测。

channel 仅 speech/image/video/music，speech 映射 registry voice。供应商目录沿用 model_registry，增加 broker_adapter、override_allowed 元数据，不另复制一套供应商注册表；保留 local 原有能力。供应商凭证 bundle 形状及必填项必须与 registry 一致，含双 Key 场景，交付时记录精确输入例子。

## 执行与验收

- [ ] **1. 先红。** 按 plan Task 4 写默认继承、换地址留空凭证拒绝测试，再执行 test_config.py，记录失败。后续按下列约束补有意义的回归，再实现最小代码。

- [ ] **2. 持久化与版本。** 按 spec 增加 ManagedRevision、WorkspaceOverride，必要表只通过追加 migration 升级当前 v2；不改 migration 1/2。保留用户、会话、Run、登录、邀请和限速记录。升级测试用冻结 v2 schema 或旧实现生成的真实库，不用当前新库重开代替迁移证明。

  publish 仅真实有效管理员可执行，授权回查数据库，不信任 Identity.role。expected_version 比较与新版本写入在同一事务；两个连接用同一旧版本发布只能一个成功，另一个 409。旧发布版本保持可识别且不可被覆盖，resolve 返回实际版本，供后续 Run 快照使用；本轮无需实现任务执行。

- [ ] **3. 秘密加密。** 使用现有 cryptography 依赖的 AES-GCM，32 字节 master key，独立随机 nonce；AAD 包含作用域与记录标识，使跨 workspace/记录替换密文不能解密。secret bundle 不能拆成逐字段混合来源。数据库、WAL、HTTP 响应、错误与日志不出现测试 sentinel 明文；不得把完整输入配置或异常内部对象直接输出。

  服务启动从显式受保护文件加载 master key，记录启动参数和装配方法；缺失、长度错误或与已有密文不匹配必须明确失败，不自动生成新 key 覆盖原文件，不将已有配置实例降级为无配置模式来掩盖错误。测试只用临时 key 文件；单纯认证边界的既有 create_app 测试可继续不装配配置服务，相关业务保持 503。ConfigService 的 DB 操作仍在 app 专用线程内执行，不跨线程传旧连接。

- [ ] **4. 完整继承语义。** 无覆盖继承最新默认；个人完整覆盖保存自己的供应商/模型/地址/协议/凭证/options，管理员更新不改写该个人路由。URL/provider/protocol 任一变化必须提供完整个人凭证；空 secret 只在既有个人同一路由下保留原个人凭证，不能复制默认 Key。清除覆盖恢复最新默认。

  managed-model 显式引用当前受管路由，只允许管理员批准的模型和非敏感参数；不能夹带地址、协议、凭证引用、env、argv 或改变底座。默认更新后引用跟随最新受管版本；个人完整路由保持独立。未知 channel/provider、chat/runtime/command/plugins/sandbox 等越权字段明确拒绝，不静默忽略后返回成功。A/B 用户保存、读取和清除互不影响，伪造 workspace 字段也不能越界。
