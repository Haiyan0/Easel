## 稳定契约

```python
authorize(actor: Identity, method: str, path: str) -> RouteDecision
# RouteDecision(kind: str, resource_type: str | None, resource_id: str | None)
verify_worker_request(headers: Mapping[str, str],
                      expected_workspace_id: str, expected_token: str) -> None
```

沿用共享 Identity/DomainError，不修改已有字段。RouteDecision 只分类候选路由，不证明资源归属；真正资源访问必须由 Store 按当前身份查询。后续服务不能把 actor 或返回的 resource_id 当作已授权对象。

worker 启用使用计划已有的 EASEL_SERVICE_MODE=worker，默认未配置为 local。实例 workspace 和服务 token 只能来自启动配置，不从请求推断；确定并记录启动配置名、内部头名及头清洗辅助函数，供后续 runtime/relay 直接复用。服务 token 不写日志、错误或普通 repr。
