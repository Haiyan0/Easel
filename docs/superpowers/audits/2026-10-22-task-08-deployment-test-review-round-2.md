## D-R2-02 [P2] 清理缺少归属校验、失败报告及异常后的继续清理

位置：同文件资源创建及第 331–338 行 finally。

客户端已使用随机测试名称，finally 也先按名删除客户端：这一部分有效，原“匿名客户端无法定位”子问题可关闭。

但上一轮同时要求的标签归属核验和清理失败可见性没有实现：

- 容器/网络创建没有本次运行标签，清理前没有 inspect 校验归属。

- 单个删除抛 TimeoutExpired 等异常时，finally 立即中断，后续资源未清理；还会覆盖原测试异常。

主审使用实际测试函数、临时 SQLite/文件及 fake Docker，客户端 run 注入 TimeoutExpired：捕获 worker_named=true、label_present=false、inspect_before_cleanup=false；清理非零被忽略。独立复审另在首个 worker rm 注入 TimeoutExpired，只有 worker 收到清理，其余 sidecar/control/两个网络都没有清理命令。

修复/验收：为所有自建容器、网络及新增测试卷附本次随机 run ID 标签；清理先核对归属，明确不存在可幂等跳过，未知归属不删除。逐项捕获清理错误并继续尝试剩余资源，汇总清理失败，不静默吞掉，不丢失原测试失败原因。不要删除非本次资源。

补不依赖 Docker 的确定性回归：客户端 CLI 超时仍可清理；归属不匹配不删除；单项删除非零或超时后仍清理其他资源且错误可见；正常和已不存在的幂等路径。纯 helper 回归应放在可正常执行的单元测试文件中，避免被集成文件的全局 skip 标记一起跳过。
