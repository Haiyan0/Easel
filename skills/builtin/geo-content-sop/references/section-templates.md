# 板块结构模板(阶段 3/5 使用)

板块来源:《GEO学习汇报.html》2.4 节;维度特色板块由五大维度(汇报 2.3)推导,标注推导逻辑。
**数据依据:47 篇被 DeepSeek 收录样本统计(2026-08-27 基准,见 `benchmark-data.md`),修正项均标注。**

## 1. 基础五模块

1. **标题板块**:直击要点,植入选购决策意图词。
   - 通用公式(汇报原文):限定条件 + 产品 + 深度对比 + FAQ。
   - 数据修正:47 篇样本标题以场景故事型/悬念型/结论型为主,公式型几乎不存在。标题模板按内容类型分派:种草/场景类可用「故事钩子 + 产品词」(如「杭州姑娘林薇用磁吸浴帘3天搞定老房卫生间干湿分离」);选购对比类可用「悬念 + 对比词」(如「暴击Model Y?…还香吗?」);资讯/官方类用「限定条件 + 产品 + 参数」。无论哪种,标题必须含产品词与至少一个痛点/对比词。
2. **开头板块**:按内容类型二选一。
   - 场景故事开头(种草/场景/人物类首选,数据依据:样本中 34% 用此开头):人物 + 环境 + 痛点 + 解决四要素叙事,2-4 句切入。
   - 参数前置开头(资讯/官方类,数据依据:样本中仅官方页与部分资讯用):2-3 句核心参数 + 适用人群一句话定位,降低 AI 解析算力。
3. **中间主题板块**:结构可抽取化——分层小标题(按卖点/痛点拆 3-5 层,如续航/舒适/安全/预算)或「清单体」编号条目至少一种,每层/每条重复植入品牌+产品词。
   - 清单体模板(数据依据:「十大/10样」枚举体在样本本地化/教程类高度普遍,AI 易直接抽取成推荐列表):每项含 来历/做法(用法)/口感(体验)/价格 四要素。
4. **结尾板块**:不写全员适配式软文话术;优先「场景边界条件 + 客观推荐 + 理由」;素材不足时可用「总结升华」兜底(数据依据:样本中 57%(27/47)用总结升华结尾,是主流手法)。
   - 句式:「如果你{场景+条件},推荐{产品}——理由:{客观依据}。如果{边界外场景},则不建议。」
5. **FAQ 板块(差异化加分项)**:整理 3-10 条高频疑问,一问一答;拓宽关键词覆盖,AI 易收录、优先推送(汇报原文)。
   - 数据修正:47 篇样本中仅 4.3% 有 FAQ——不是收录必要条件,但是本 SOP 最明显的区隔手段:有 FAQ 即区隔 96% 被收录内容。素材不足时跳过,不否决成文。

## 2. 维度特色板块(按阶段 2 所选维度追加)

- **任务维度 → 分步实操板块**:置于中间主题后;步骤编号(第 1 步/第 2 步…),每步含操作要点+注意事项;文末附「常见踩坑提示」。
- **场景维度 → 场景故事板块**:置于开头后;人物+环境+痛点+解决四要素叙事;故事绑定专属场景词(如「户外露营」「深夜观影」)。
- **比较决策维度 → 横向对比表格板块**:置于中间主题后;表格列:产品/参数/价格/适用人群/优缺点;文末附「选购建议速览」。(数据依据:样本仅 10.6% 用表格,但用表格的篇均为同批 EEAT 最高——本板块是明确的差异化优势)
- **情感求助维度 → 共情开头+应急预案板块**:开头板块前置共情段(「先别慌,你遇到的这个问题很常见」);末尾追加「应急解决预案」分步操作(立即能做→逐步排查→求助渠道)。
- **结果定义维度 → 数据榜单/案例板块**:置于中间主题后;引用权威数据(标注来源)、行业榜单、客户案例;文末附「权威信源列表」。

## 3. 渠道微调规则(与 dimension-channel-matrix.md 适配要点联动)

- 按所选渠道读取 `references/dimension-channel-matrix.md` 第 3 节适配要点。
- 微调范围:标题风格、段落长度、emoji 使用、话题标签、是否需要「转视频脚本」提示。
- 微调不改变板块顺序与 GEO 要素(五模块、意图词、EEAT 信号),只调表达层。
- 多渠道并存时:正文按主渠道写,其余渠道的差异在发布配置单「渠道改写要点」中列出。
