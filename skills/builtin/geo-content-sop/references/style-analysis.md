# 范文解析与仿写方法(阶段 0/5 使用,可选能力)

## 1. 范文来源(三种形式均支持)

- **网页 URL**：用运行环境提供的联网抓取工具读取正文；没有抓取工具或抓取失败时，请用户粘贴文本，或改用 `scripts/web_search.py` 的检索摘要（摘要不能当全文）。
- **粘贴文本**：直接接收用户粘贴的全文。
- **本地文件**：读取本机 `.md/.txt/.html`；DOCX 用 Python 标准库提取段落与表格，不保证版式还原、不做 OCR。

## 2. 解析内容 → 产出「范文风格卡」

从范文提取以下三个维度,输出结构化「范文风格卡」记入 `_working-data.md`:

1. **结构骨架**
   - 标题层级与数量;标题句式(问题式/悬念式/结论式)
   - 板块顺序(开头手法、正文分层方式、结尾手法)
   - 段落节奏(短段落流/长段落论述/两者交替)
2. **语言风格**
   - 句式长短(平均句长、是否多用短句)
   - 语气(口语化/书面化/对话感)
   - 专业术语密度(术语多/少/术语+通俗解释)
   - 修辞与点缀(emoji 使用频率、金句频率、设问/反问使用)
3. **GEO 要素手法**
   - 范文的意图词植入方式(标题/开头/小标题中的词)
   - EEAT 信号呈现手法(案例佐证、数据引用、背书展示)

风格卡输出格式:

```
【范文风格卡】来源:xxx
- 结构:标题式(…)、开头手法(…)、分层方式(…)、结尾手法(…)
- 语言:句式(…)、语气(…)、术语密度(…)、emoji/金句(…)
- GEO 手法:意图词植入(…)、EEAT 信号(…)
```

## 3. 仿写红线(必须遵守)

- **只仿结构与风格,不仿内容**:正文素材 100% 来自用户交互收集的材料;禁止照搬范文的观点、案例、数据、表述。
- **GEO 规范优先**:范文风格与 GEO 规范冲突时(如范文无 FAQ 板块、开头无核心参数前置),GEO 规范优先——基础五模块必须保留,范文风格只作用于语言表达层。
  数据依据:47 篇样本中 FAQ 覆盖率仅 4.3%、参数前置开头仅 1 篇,该两项现为差异化/分派口径而非强制项,见 `references/section-templates.md`。
- 阶段 3 中范文结构骨架仅作为「参考候选」展示,采纳与否由用户决定。
