# GEO 文章评分手册(阶段 5 使用)

数据依据:47 篇被 DeepSeek 收录样本统计(见 `benchmark-data.md`,2026-08-27 基准)。
评分只针对 skill 自产文章;收录样本不参与评分,仅作基准(样本是已通过 AI 筛选的正样本)。

## 1. 评分表(满分 100)

| 维度 | 满分 | 评分细则(0 / 半 / 满分) | 基准对比 |
|---|---|---|---|
| E 经验 | 15 | 0 分:无任何第一人称、场景、使用细节;7.5 分:有第一人称或场景描写,但细节薄;15 分:具体场景(人物/环境/时间)+ 可感知使用细节 | 有 |
| E 专业 | 20 | 0 分:无术语、无参数、无数据;10 分:有术语或少量参数,无深入讲解;20 分:参数数据密集 + 原理/机制讲解 | 有 |
| A 权威 | 15 | 0 分:无来源、无署名、无背书;7.5 分:有署名 + 发布时间,或引用不可验证来源;15 分:引用可验证来源(官网/官方公告/检测报告/政府公示/媒体)或有明确专家/机构背书 | 有 |
| T 信任 | 15 | 0 分:匿名且无时效信息;7.5 分:署名或日期仅其一,或内容明显只吹不贬;15 分:署名 + 日期 + 客观讲边界(缺点与场景边界也讲) | 有 |
| 结构可抽取性 | 15 | 0 分:无小标题、无列表、无表格;5 分:三者其一;10 分:有其二;15 分:小标题 + 列表 + 表格齐备 | 无 |
| 意图词覆盖 | 10 | 产品/服务词 3 分、痛点/问题词 3 分、对比决策词 4 分;缺一类扣对应分 | 无 |
| 可验证性 | 10 | 0 分:文中数据无来源;5 分:部分数据有来源;10 分:关键数据全部带来源 | 无 |
| 合计 | 100 | — | — |

## 2. 编造红线(一票否决)

正文出现「具名人物 / 具体数字无来源痕迹」即判定**不合格**,不参与计分:

- 判定要点:①出现具体人名 + 情节故事但无任何来源痕迹;②出现精确数字(如「80%」「3.2 倍」)但无出处。
- 触发后:立即中止交付,向用户指出具体编造点;改写后**全量重评**。

## 3. 档位

- **≥85 优秀**:直接交付
- **70-84 良好**:可交付,评分卡附短板提示
- **<70 需修正**:回到阶段 4 补素材或阶段 5 改写,重评
- 编造红线触发:**不合格**

## 4. 评分卡模板

```markdown
# {选题} 评分卡

- 总分 {N} / 100 —— {档位}
- E经验 {x}/15 · E专业 {x}/20 · A权威 {x}/15({基准对比:超过 X% 被收录样本})
- T信任 {x}/15 · 结构可抽取性 {x}/15 · 意图词 {x}/10 · 可验证性 {x}/10
- 编造红线:未触发 / 已触发(不合格)
- 短板项:{逐条列出低于满分的维度及原因;素材缺失的维度标注「素材缺失」}
- 复核记录:{用户异议 → 补素材 → 单项重评记录;无则写「无」}
```

## 5. 基准对比计算

- 仅 EEAT 四维做基准对比:按该维得分(0/7.5/15 或 0/10/20 对应样本 0/1/2 档)查 `benchmark-data.md`「超过 X% 样本」对照表。
- 写法示例:「A权威 7.5/15(超过 43% 被收录样本)」。
- 基准更新后自动采用新表;旧口径见 benchmark-data 历史快照。

## 6. 复核规则

- 用户对单项分数有异议:允许补充素材后仅重评该单项;重评记录写入评分卡「复核记录」。
- 某维素材缺失导致 0 分:评分卡标注「素材缺失」,短板提示回阶段 4 补素材。
