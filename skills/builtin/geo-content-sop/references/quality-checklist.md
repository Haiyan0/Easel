# 成文 GEO 自检清单(阶段 5 使用)

逐项检查,不通过项立即修正。检查依据:《GEO学习汇报.html》第一、二部分;勾选通过后再按 `scoring-rubric.md` 量化评分。
**数据依据:47 篇被 DeepSeek 收录样本统计(2026-08-27 基准),见 `benchmark-data.md`。**

## 1. EEAT 四维

- [ ] Experience:正文有具体案例/实测佐证,无空泛表述?
- [ ] Expertise:行业关键词与专业术语已深度植入?
- [ ] Authoritativeness:资质/团队/案例/实体/荣誉/口碑至少 1 类出现?
- [ ] Trust:无夸大、无越界承诺,边界披露明确?

## 2. 优化三方向

- [ ] 时效性:有无标注更新节点/版本信息?
- [ ] 场景化:内容绑定真实使用场景(人群/环境/痛点)?
- [ ] 可验证:**硬检查**——每个数据点必须有来源(数据带来源);无来源数据删除或标注,不得保留「裸数据」?(数据依据:47 篇样本仅 31.9% 做到,是本 SOP 的核心差异化项)
- [ ] 信息增量:文章含至少 1 个「经验修正/划定边界/颠覆认知」增量点,而非泛科普?
- [ ] 术语+通俗:专业术语后跟通俗解释?

## 3. 意图词覆盖

- [ ] 产品/服务词:标题+开头+小标题均有植入?
- [ ] 痛点/问题词:至少 2 个用户痛点被覆盖?
- [ ] 对比决策词:涉及选购时有参数/对比词汇?

## 4. 结构与一致性

- [ ] 结构可抽取:小标题/编号列表/表格至少一种,便于 AI 摘取?(数据依据:47 篇样本中仅 10.6%(5/47)用表格,口径同 `benchmark-data.md` 稀缺项覆盖率;36% 用列表、约四分之一有小标题)
- [ ] FAQ 定位:**差异化加分项**——有 FAQ 即区隔 96% 被收录内容(数据依据:样本 FAQ 覆盖率仅 4.3%);素材不足时可跳过,不否决成文
- [ ] 信源一致:文中信息与用户提供的信源无矛盾?
- [ ] 原创性(仅范文仿写时):无照搬范文观点/案例/表述?

## 5. 编造红线(与 scoring-rubric.md 第 2 节一致,显式检查)

- [ ] 无具名人物+情节故事但无来源痕迹的表述?
- [ ] 无精确数字(如「80%」「3.2 倍」)无出处的表述?
- 任一命中 → 判定不合格,改写后重检。

## 6. 修正原则

- 缺什么补什么;无法补充的素材按「宁缺毋滥」原则弱化对应表述,不编造。
- 勾选清单通过后,按 `scoring-rubric.md` 评分表量化打分(满分 100),档位与交付规则见评分手册第 3 节。
