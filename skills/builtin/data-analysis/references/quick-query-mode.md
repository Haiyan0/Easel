# 轻量查询模式

适用于查一个数、筛选或简单分组统计。按文件流程准备输入，对影响本次计算的字段执行最小质量检查；已有本次输入的检查结果可以复用。

用户已给出的口径不重复追问。目标、单位、分母或时间不明确且会影响结论时，一次问清关键缺口；不影响结果的信息标注未知。

## 答案结构

1. **答案**：所求数值/小表，单位清晰；保留足够精度用于计算，展示时再舍入。
2. **口径与来源**：来源文件/工作表、时间范围、筛选条件、公式或分母。
3. **关键限制**：仅列会影响该答案的缺失、公式不可用、重复风险或覆盖不足；说明这是全量结果还是限定范围结果。

只查一个数时不制作完整报告或一套图表。用户明确要求图表或多维分析时直接切换完整模式，说明所选模式即可，无需另行确认模式切换。

检查关键数字及分母；存在阻断问题时给出可核实部分，不把缺失补零、不把无法读取的公式值算作零。用户明确要求的真正缺失值处理可执行，但需注明处理规则、数量和影响。
