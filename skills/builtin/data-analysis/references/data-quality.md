# 数据质量与处理记录

## 先确认一行代表什么

记录文件路径、工作表、读取范围、行列数、业务粒度、候选唯一键、时间字段及覆盖范围。订单明细不能直接当订单数；用户快照不能直接当新增用户。无法确定时明确假设，并限制受影响的结论。

逐列检查类型、缺失数量及比例、数值零值、日期解析失败、类别数量。分别统计整行重复与业务键重复，说明数量指“涉及的全部行”还是“多余行”。重复可能是合法明细；未经业务规则确认不能删。预览或抽样只能代表已读取范围，不能称为全量检查。

连接数据前声明预期关系，用 merge 的 validate 参数验证；比较连接前后行数、唯一键和关键金额，检查未匹配记录。多对多放大不能用事后去重掩盖。

## 区分缺失、零、异常

- 缺失是未知，零是观测值；金额、公式结果缺失不能自动填零。全空分组汇总用 min_count=1 保留未知。
- 日期或数值转换失败单独计数，保留原字段，不静默丢行。
- 退款等负数是否有效由字段含义决定；不要笼统视为脏数据。
- 异常点先核实，再报告含全部有效观测的结果、中位数及标记异常点后的敏感性结果。IQR 只是候选标记，不能证明记录错误。小样本、偏态、分组分布差异可能使标记不稳定。
- 清洗在副本上进行，原始输入只读。记录每项规则、受影响行数、理由及处理前后指标。不要为迎合用户想要的结论过滤数据。

## Excel 公式专项检查

对参与指标的 xlsx 工作表，分别用 openpyxl 的 data_only=False 和 True 读取，核对公式单元格及对应缓存。pandas.read_excel 不计算公式：空缓存可能呈现为缺失，不能被 fillna(0) 掩盖。缓存是 Excel 上次保存的结果，存在缓存也不能证明已更新。

记录公式数量、不可用缓存数量、缓存错误数量及影响字段。错误类型包含 Excel 的 #DIV/0! 等。发现外部链接、公式缓存异常或无法验证的新鲜度时说明限制；关键指标无法计算则标为“暂不可用于该结论”。可以交付可靠的非公式字段结果，但不能把部分和称为完整金额。

当前环境不保证安装 Excel/LibreOffice，不得声称执行过重算。需要时请用户提供重新计算并保存的工作簿或可信数值导出。xls 用 xlrd 读取，但当前参考方法不能提供同等公式审计，需明确限制；不要宣称无公式风险。

参考 analysis-patterns.md 的代码只是检查起点；仍需判断业务含义、数据范围与公式缓存来源。
