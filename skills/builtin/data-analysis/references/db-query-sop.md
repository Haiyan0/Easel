# 用户文件读取与分析 SOP

本页适用于用户提供的 CSV/Excel/JSON 文件。企业或项目数据库先按 database-analysis.md 选项目、核验口径和查询，保存结果为 JSON 后接入相同质量与交付流程。

1. 明确目标：问题、指标公式、单位、时间/时区、观察粒度。订单明细行数不等于订单数；自然键未知时标记未知，不自行认定重复记录可删。
2. 定位输入：确认文件路径。对话附件以本轮系统附件清单为准；需要纳入项目时复制到 `outputs/<主题>/assets/`，保留原件。记录来源名、文件路径、SHA-256、工作表与来源时点（未知时写未知）。
3. 检查结构：确认标题行、编码、列类型、行列数、日期覆盖。明确全量读取或抽样/分块范围；读取前缀不能代表全量。xlsx 在读取金额等公式指标前按 data-quality.md 检查公式缓存。
4. 判断覆盖：结合实际字段核对分析目标；必要字段、关键值缺失或公式不可用时说明缺口，只分析可支撑部分。按 data-quality.md 汇总质量问题与影响。
5. 计算复核：按确认条件筛选/聚合，记录输入、筛选后、有效和排除记录数。参考 statistics-rules.md；合并前核对键关系，合并后检查行数及总额。保留原数据，派生结果写新文件。
6. 交付：轻量模式直接回答；完整模式根据 output-spec.md 生成报告和必要文件，按 validation-checklist.md 给出审核状态，检查脚本退出状态并确认产物文件真实存在。

上下文纪律见 data-reading-rules.md；常用可执行检查见 analysis-patterns.md。
