# 交付前验证

对影响结论的项目实际执行检查，记录方法和结果。未执行写“未检查及原因”，不因读过本清单就声称已核验。

| 检查 | 应保存的证据 |
| --- | --- |
| 来源与范围 | 文件路径、工作表、读取行数、日期边界；可取得时保存摘要 |
| 粒度与重复 | 行含义、键、整行/键重复数量；合法重复的处理理由 |
| 连接 | 预期关系、验证结果、前后行数/金额及未匹配数量；无连接则不适用 |
| 指标 | 分子/分母、去重及权重；分母为零/缺失的数量 |
| 期间 | 本期/基期实际覆盖天数、完整性、时区与对齐方式 |
| 汇总 | 独立计算的总计与分项对账；重叠类别不能强制加和 |
| 缺失与异常 | 空值/零值分别统计、转换失败、清洗记录、敏感性结果 |
| Excel | 关键字段公式缓存可用性、错误、未重算及新鲜度限制 |
| 图表与文件 | 表图关键数字一致、单位与轴、实际生成文件、文件路径 |

独立核验至少覆盖决定性指标：例如主流程 groupby 汇总，另用原始明细筛选后求和或已知样本手算核对。用同一汇总结果绘图并读回不能证明计算正确。分组有重叠、排除项、退款或未知金额时记录对账差异原因，不能硬凑相等。

逐个结论给交付判断：

- **可交付**：支持该结论的检查已执行，未发现实质缺口；仍报告一般假设。
- **带限制交付**：可以给出部分可靠事实，但范围、缓存新鲜度等限制影响解释；明确影响哪些结论。
- **暂不可用于该结论**：关键公式值缺失、分母不明、连接放大未解决或期间不可比等导致该结论不成立。可交付其他不受影响的事实及补救方法。

判断不是评分，也不是全文件统一标签；不得用固定缺失率或样本量阈值替代业务判断。
