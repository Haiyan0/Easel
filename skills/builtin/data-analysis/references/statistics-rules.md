# 统计口径与解释

1. 每项指标写出粒度、过滤条件、单位、分子、分母、去重键、时间窗。转换率要求分子属于分母对应群体；百分数差用百分点，相对变化用百分比。
2. 汇总转换率使用总分子 / 总分母，不平均各组比例。平均客单价用总金额 / 对应订单数；分组均值需要按相应样本量加权。分母为零、缺失、无穷或群体不匹配时结果为不可计算，不能写成 0%。safe_rate 适用于受限于 0 到 1 的比例，不适用于每用户订单数等无上界指标。
3. 增长率为 (本期 - 上期) / 上期；上期为零或负值时不套普通增长率，优先给绝对变化与业务解释。全空金额不能汇总成零。
4. 比较相同长度、覆盖率、时区和业务口径的时间窗。月初至今对整月只能给原始观察，不能直接当环比。若有日期明细，对齐双方同日范围，并注明节假日、缺报和未完结周期。日均只是一种标准化，不能自动消除季节性差异。
5. 同时看总量、分组及组权重变化，识别结构影响。总体改善可能伴随每组下降；固定基期权重可作敏感性分析，并明确权重选择，不称为真实反事实。
6. 描述偏态数值时给均值、中位数、有效样本数和范围；异常值结果遵循 data-quality.md。缺失率按实际检查范围计算，不设通用的合格阈值。
7. 描述性趋势不能证明活动、渠道等造成变化。分开呈现事实、待验证解释和建议；提出解释所需的补充数据或实验。
8. 只有用户目标确实需要且数据设计支持时才做统计推断。先确认独立观测单位、重复观测、配对关系、样本选择和多重比较；报告效应量及适当区间，并区分探索与预先设定的验证。当前没有专用推断库，不编造检验、p 值或置信区间，也运行时无网络，不临时安装。不能实施时交付描述性结果及限制。
