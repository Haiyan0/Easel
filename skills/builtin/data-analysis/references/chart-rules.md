# 按分析目的制图

| 要表达的问题 | 优先图表 |
| --- | --- |
| 连续时间的趋势与变化 | 折线图；稀疏时间点也可用带点折线 |
| 类别之间的大小、排名 | 排序柱状图；长类别名用横向柱状 |
| 数值分布与异常 | 直方图或箱线图，注明有效样本量 |
| 两个数值的关联 | 散点图；相关性不能证明因果 |
| 整体的构成 | 少量互斥类别可用饼图，比较构成优先堆叠柱状 |

按问题选图，不仅凭时间粒度。饼图需要非负、互斥、覆盖同一整体且总量大于零的数据；退款负值、重叠分类或全零不能做饼图。Top N 应说明截断，构成图可汇总“其他”，不能让部分数据看似整体。

柱状图数值轴从零起。折线图可采用更窄范围，但明确刻度，不能视觉夸大变化；分面比较使用可比尺度。不同单位/量级优先拆图，避免让双轴制造关系。金额、数量、比例的单位、期间与口径标在轴或说明中；比例明确百分比，差异明确百分点。

标题指出有证据的发现，标注必要的峰谷和异常，不把未核实解释写进标题。颜色含义一致，结合标记/线型，避免只靠红绿区分；图例清楚、文字可读、不过度标注密集点。表图的关键数字必须一致，缺失时间不应默认为零或未经说明跨缺口连线。

用项目 Python 生成 PNG 或 HTML。matplotlib 使用 Agg 和环境中文字体，缓存目录保持可写。Plotly 的 write_html(..., include_plotlyjs=True) 内嵌脚本以便离线打开；时间范围筛选仅在有助于探索的 HTML 中提供，不要求 PNG 具备交互。

保存到 `outputs/<主题>/assets/` 或项目根成品目录，交付前确认文件真实存在。简单问题不强制生成图；每张图都应服务一个明确发现。交付前检查单位、范围、零基线、缺失处理、表图数字、中文显示和实际文件输出。
