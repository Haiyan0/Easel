# 安全边界与资源限制

## 三层只读防线

1. **AST 白名单**：完整 SQL 用 MySQL 方言解析，恰好一条只读语句；递归校验全部节点、CTE、子查询与函数；未覆盖结构默认拒绝；执行的是校验通过的 AST **受控重建**结果。
2. **数据库只读事务**：连接后执行固定内部语句建立只读事务并设置服务端 SELECT 超时，**读回校验**实际生效；设置失败立即停止，不降级为普通事务。
3. **最小权限账号**：数据库端只读、限定表权限。`readonly_account_verified` 只是部署检查记录，不能代替数据库真实权限校验。

## 允许与拒绝（首版）

- 允许：普通 SELECT、只读非递归 CTE、UNION、受限 JOIN、聚合、排序、过滤、白名单内置函数。
- 拒绝：写语句/DDL/事务命令、多语句、注释与优化器 hint、锁、`INTO`、用户变量、递归 CTE、笛卡尔连接、跨库与三段名、未授权表、未登记函数、非零 OFFSET、非字面量 LIMIT、视图（describe 明确报告不支持）。
- 参数只支持命名占位符 `:name`，并与提供的参数键集合**精确匹配**；任何值都由驱动绑定，不拼进 SQL 文本。

## 资源限制

| 项目 | 限制 |
| --- | --- |
| SQL 文本 | ≤ 32 KiB |
| 返回行数 | 默认 200，硬上限 1000（额外读 1 行做截断探针） |
| 输出 | 256 KiB |
| 单字段 | 16 KiB |
| 建连 | 5 秒 |
| 单次 SELECT | 10 秒（服务端超时 + 客户端预算） |
| 总执行 | 15 秒 |
| 清理 | 3 秒 |
| 每运行调用 | 最多 40 次 |
| 每运行累计行数 | 最多 10000 行 |
| 并发 | 单数据源 2、全局 8 |
| 租约 | 30 秒到期 |

取消与超时路径会销毁连接而不是归还池；清理失败不跳过后续清理步骤。

## 多人 Docker 的共享凭据边界

- 所有 workspace 共用同一组只读 DSN 与同一把 SSH 私钥；任一用户通过 agent 读取 DSN 后，可在自己的 workspace 内直接使用该只读账号。数据库账号必须是最小权限只读账号。
- `database-query.env` 以只读文件挂载在 worker 内，agent 可在会话中读取；它不是对 agent 的保密边界，只用于把 DSN 从进程环境中拿掉。
- `allowed_schema` 与 `allowed_tables` 只是技能侧白名单，**不是**数据库权限边界；真实权限由数据库账号授予。
- SSH 私钥只在 sidecar 的只读挂载中，worker 不挂载 `keys/`，agent 不可读取私钥。每 workspace 各自建立 SSH 连接，跳板机需允许相应并发。
- `tunnel.multiuser.yaml` 与 `config.multiuser.yaml` 只含数据库/跳板机主机名、端口与表名，随镜像分发；不得在其中写入 DSN、口令或私钥。
- worker 进程环境由 `build_run_env` 的 allowlist 重建，DSN 不进入环境变量；技能只通过 `--env-file /run/easel-secrets/database-query.env` 读取凭据。不要在 provisioner 给 worker 的 Docker `--env-file` 或 `--env` 中放 DSN。
- 轮换 DSN 或私钥后必须重建对应 worker/sidecar；运行中的容器不会自动看到新内容。

## 不保证事项

- **技能不是权限边界**：拥有文件和 Shell 权限的 Agent 仍可能直接读取凭据或绕开脚本。若要求集中撤权、统一审计与强制防绕过，应使用独立服务或 MCP 网关，属于另一种部署方案。
- 本地预算只在本机生效，不是跨主机配额，也不能阻止持有凭据者绕过。
- `tables` 返回配置白名单，不保证表真实存在；共享连接采用连接级表白名单，没有额外的项目级表隔离。
- 首版不支持全部只读 SQL，也不支持跨库、全量扫描、MCP 或其他数据库。
- 业务口径由文档与用户确认；脚本只能证明连接与绑定有效，不能证明 Agent 已正确理解业务口径。
- 结果文件可能包含业务信息与参数，应放在私有输出目录，不输出 URL、口令或私钥。
